# Rock Paper Scissor Game

A simple Rock Paper Scissor game developed in Python. The game allows the user to play against the computer using either numbers or text as input.

## Features

- User vs Computer gameplay
- Accepts input as text or number
- Random computer choice
- Displays the winner
- Easy to understand Python code
- Beginner-friendly project

## Technologies Used

- Python 3

## Input Options

You can enter:

- Rock or 1
- Paper or 2
- Scissor or 3

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code or any Python IDE.
3. Run the Python file.
4. Enter your choice and enjoy the game.

## Project Output

- User selects Rock, Paper, or Scissor.
- Computer generates a random choice.
- The program compares both choices.
- The winner is displayed.
